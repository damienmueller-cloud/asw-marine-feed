# ASW Marine Parts product feed

Public product catalogue feed for [ASW Marine Parts](https://www.aswmarineparts.com.au/), in [Google Merchant Center](https://support.google.com/merchants/answer/7052112) text format (one row per size or variant). The same file can be fetched by Meta Commerce Manager.

This repository contains only public product information: titles, prices including GST in AUD, product links, and image URLs. It has no passwords, API keys, or customer data.

## Feed URLs

- TSV: https://damienmueller-cloud.github.io/asw-marine-feed/asw_products.tsv
- CSV (same rows): https://damienmueller-cloud.github.io/asw-marine-feed/asw_products.csv

The shop is [aswmarineparts.com.au/store-1](https://www.aswmarineparts.com.au/store-1).
